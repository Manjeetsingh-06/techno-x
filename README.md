# Techno-X — Campus Event & Student Activity Portal

A modern, full-stack campus management and event portal designed for Techno Group of Institutions (TGI).

## Features
- **Role-based Authentication**: JWT-based auth for Students, Faculty, Management Committee, and Administrators.
- **Event Management**: Event creation, registration, ticketing with QR codes, and approval workflows.
- **Attendance System**: Live barcode/QR code ticket scanning and verification.
- **Announcements & Notifications**: Multi-channel broadcast notifications.
- **Reports & Analytics**: Comprehensive dashboards for student engagement, event metrics, and downloads.

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Recharts
- **Backend**: Spring Boot 3, Java 21, Spring Security, Hibernate/JPA
- **Database**: TiDB Serverless (MySQL-compatible)
- **Deployment**: Vercel (Frontend), Render / Railway (Backend)
